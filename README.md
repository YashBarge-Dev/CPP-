# C++ Learning Journey — CDAC PG-DAC

## About This Repository
This repository documents my day-by-day C++ learning journey while pursuing the **CDAC PG-DAC (Post Graduate Diploma in Advanced Computing)** course. It contains the programs I write, concepts I learn, practical exercises, and assignments I complete throughout the course.

## Topics Covered

### 1. C++ Fundamentals
- Introduction to C++ and Program Structure
- Variables, Data Types, and Operators
- Input and Output Operations
- Conditional Statements and Loops
- Functions and Recursion
- Function Overloading and Parameter Passing

### 2. Data Types and Memory
- Arrays and Strings
- Pointers and References
- Structures, Unions, and Enumerations
- Dynamic Memory Allocation
- Type Casting and Memory Management

### 3. Object-Oriented Programming (OOP)
- Classes and Objects
- Access Specifiers and Encapsulation
- Constructors and Destructors
- The `this` Pointer
- Static Members and Constant Members
- Friend Functions and Friend Classes
- Inheritance and Its Types
- Polymorphism: Compile-Time and Run-Time
- Function and Operator Overloading
- Virtual Functions and Abstract Classes
- Abstraction and Data Hiding

### 4. Advanced C++ Concepts
- Exception Handling (`try`, `catch`, and `throw`)
- File Handling and File Streams
- Templates and Generic Programming
- Runtime Type Information (RTTI)
- Type Casting: `static_cast`, `dynamic_cast`, `const_cast`, and `reinterpret_cast`

### 5. Standard Template Library (STL)
- Containers
- Iterators
- Algorithms
- Function Objects and Related STL Utilities
- Sequence, Associative, and Unordered Containers

### 6. Practical Programming
- Daily Coding Exercises
- Logic-Building and Problem-Solving Programs
- Course Assignments
- File-Based Applications
- Mini-Projects and Practical Implementations

## Repository Organization
Programs and concepts are organized by day or topic to make them easy to navigate, understand, and revise. The repository serves as my personal learning log, revision resource, and portfolio of practical C++ programming.

## Objective
My goal is to strengthen my C++ fundamentals, develop problem-solving skills, understand object-oriented programming, and maintain a structured reference for course revision, practical examinations, technical interviews, and future software development projects.

*This repository will continue to grow as I learn and practise new concepts throughout the CDAC PG-DAC course.*
